# BODYCAM // AXON BODY 3 SIMULATOR

Ультрареалістичний тактичний шутер від першої особи у браузері (Three.js + WebGL GLSL Shaders + Web Audio API), що імітує оперативний відеозапис із нагрудної камери спецпризначенця **AXON BODY 3**.

## Основні можливості

- **Оптика нагрудної камери (`AXON BODY 3`)**:
  - Точка огляду на рівні грудей (`y = 1.32m`), лінза «риб'яче око» (**Barrel / Fisheye Distortion**), хроматичні аберації, автоекспозиція матриці, ISO-шум та H.264-артефакти.
  - **Окуляри нічного бачення `AN/PVS-31` (`[N]`)** із зеленим люмінофором та ІЧ-лазером `AN/PEQ-15`.
  - **Краплі крові на лінзі камери** з фізичним заломленням сцени та стіканням униз під дією гравітації.
- **Біофізичні шейдери персонажів та рідин (рівень UE5)**:
  - **Трьохшарова біофізика шкіри + BSSRDF**: ліпідна плівка себуму й поту (`Sweat / Sebum Layer`), епідерміс із меланіном, дерма з гемоглобіном та підповерхневим розсіюванням світла на 2–5 мм.
  - **Динамічний кровотік (`Dynamic Blood Flow`)** та **пушок на обличчі (`Peach Fuzz / Vellus Hair`)**.
  - **Шейдер волосся та брів за моделлю Маршнера (`Marschner Hair Model`: шляхи `R`, `TT`, `TRT`)**.
  - **Живі очі (`Eye Shader`)**: динамічне розширення зіниць від темряви та адреналіну, капілярна сітка склери, заломлююча рогівка та слізне озерце.
  - **Тактична тканина `Cordura 1000D` (`Cloth Shading Model`)** та **балістичні окуляри (`Thin Translucent`)**.
  - **Колоїдна кров**: DBuffer-декалі з паралаксом, поверхневим натягом, рубіновим SSS по краях, висиханням/коагуляцією за 10–25 секунд та Niagara-частинками (`Blood Mist` + балістичні краплі).
- **Автентичний звук мікрофона бодікамери**:
  - Процедурний синтез пострілів з жорстким перевантаженням мембрани мікрофона (**Hard Clipping**), луною, гільзами, диханням та контузією (тінітус).
  - Швидке вимкнення/увімкнення звуку на клавішу **`[Z]`**.
- **Ігрові режими та 5 карт**:
  - **Командний бій 5v5 (`SWAT vs OPFOR`)** та **Deathmatch (FFA)** з автоматичною ротацією карт кожні **60 секунд**.
  - **5 локацій**: `Денний ліс (Сонячна галявина)`, `Нічний ліс (Місячна хаща)`, `Сонячний склад`, `Дах хмарочоса (Геліпад)`, `Пустельний комплекс`.

## Керування

| Клавіша | Дія |
| :--- | :--- |
| `W, A, S, D` + `Shift` | Пересування / Тактичний спринт |
| `Миша` + `ЛКМ` / `ПКМ` | Вільне прицілювання (**Free-Aim**) / Вогонь / Приціл |
| `Q` / `E` | Тактичний нахил корпусу за ріг (**Lean**) |
| `R` / `T` | Перезаряджання / Дієгетична перевірка прозорого магазину PMAG |
| `N` | Окуляри нічного бачення **AN/PVS-31** + ІЧ-лазер |
| `F` / `G` | Тактичний ліхтар / Світлошумова граната **M84 Flashbang** |
| `M` | Миттєва зміна карти |
| `Z` | Режим без звуку (**Mute**) |
| `Tab` | Меню налаштування оптики та режимів |
